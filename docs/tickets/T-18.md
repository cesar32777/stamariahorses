  URLs**. No hay histórico que preservar (el sitio no está indexado), pero el build falla si dos
  nombres colapsan al mismo slug — la guarda ya existe, no la quites.
- **El caballo 07 está `retirado`**: tiene que seguir sin ruta y sin aparecer en el grid.
- **Cero em-dash** en cualquier valor visible (decisión 9).
- `npm run build` es la red: un tipo mal puesto en el JSON rompe el build con el nombre del
  caballo (T-02). No hace falta test nuevo.
